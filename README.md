QQMusic Player (Vue3) Demo

本项目为 Vue3 + Vite 的前端练习/课程作业项目，参考示范 Demo：  

https://qqmusic-team.github.io/qqmusic-player-vue3/

---

1. 运行环境要求

在开始之前，请确保电脑已安装以下软件：

- Node.js（建议 16+ 或 18+）  
  下载地址：https://nodejs.org/
- npm（安装 Node.js 会自带 npm）

检查是否安装成功（可选）

在命令行/终端输入：

    node -v
    npm -v

1. 获取项目代码（下载/克隆）
   方式 A：使用 git clone（推荐）

1）打开命令行/终端

2）进入你想放项目的目录，例如：

    cd Desktop

3）克隆仓库到本地：

    git clone https://github.com/qqmusic-team/qqmusic-player-vue3.git

4）进入项目目录：

    cd qqmusic-player-vue3

方式 B：直接下载 ZIP

1）在 GitHub 仓库页面点击：Code -> Download ZIP

2）解压 ZIP

3）用命令行进入解压后的项目目录（或用编辑器打开）

1. 安装依赖（npm install）

在项目根目录（能看到 package.json 的目录）执行：

    npm install

1. 启动项目（开发环境）

执行：

    npm run dev

启动成功后，终端会出现类似提示（端口可能不同）：

Local: http://localhost:5173/

打开浏览器访问该地址即可运行项目。

1. 构建打包（可选）

需要查看打包结果，可执行：

    npm run build

打包完成后会生成 dist/ 目录。

1. 本地预览打包结果（可选）
   执行：
       npm run preview
